## 备份/

**用于还原的备份文件，请勿随意删除。**

| 项目 | 说明 |
| --- | --- |
| `recovered/` | 从官方 ISO 的 install.wim 提取的 6 个 LKG 原装包（含微软签名），共 115 项 |
| `lkg-safety-backup/` | DISM 修复前的 LKG 包安全备份（121 项） |
| `pkg-backup/` | 注册尝试前的包备份（26 项） |
| `LKG.SpeechRuntime.manifest.xml` | 语音引擎包清单原文（取自 AppRepository） |
| `wu-policy-backup.reg` | WUB 写入的 Windows 更新策略备份 |
| `wu-gpcache-backup.reg` | WUB 写入的更新策略缓存备份 |

### 还原方法

```powershell
# 还原 Windows 更新策略（如需恢复 WUB 的封锁状态）
reg import "C:\hidisp\语音输入修复\备份\wu-policy-backup.reg"
reg import "C:\hidisp\语音输入修复\备份\wu-gpcache-backup.reg"

# 还原系统应用包文件（如需重新放置语音引擎）
Copy-Item "C:\hidisp\语音输入修复\备份\recovered\*" "C:\Windows\SystemApps\LKG\" -Recurse -Force
```
